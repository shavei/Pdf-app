# Privacy Policy — PDF-App

_Last updated: 2026-06-29_

PDF-App is designed to respect your privacy completely.

## Data we collect

**None.** PDF-App does not collect, store, transmit, or share any personal data.

- The app has no user accounts and no sign-in.
- The app does not connect to the internet and contains no analytics,
  advertising, or tracking SDKs.
- PDF files you open and edit are processed entirely on your device. Edited
  files are written only to the location you choose through Android's system file
  picker (Storage Access Framework). The app does not request broad storage
  permissions.

## Permissions

PDF-App does not request the internet permission and does not request broad
storage access. File access is mediated entirely by the Android system file
picker, which grants access only to the specific files you select.

## Children's privacy

Because the app collects no data at all, it collects no data from children.

## Changes to this policy

If this policy changes, the updated version will be published at this location
with a new "Last updated" date.
